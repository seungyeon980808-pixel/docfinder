Google Drive 연결

개인용 또는 학교 내부용 OAuth 웹 클라이언트 ID를 사용합니다. 액세스 토큰은 브라우저 메모리에만 보관됩니다.

편집기 URL 뒤에 source, fileId, name 쿼리가 전달됩니다. URL에 {source} 같은 자리표시자를 직접 넣을 수도 있습니다.

권한 구성
  1. Google Cloud에서 Drive API를 사용 설정합니다.
  2. 웹 애플리케이션 OAuth 클라이언트를 만듭니다.
  3. 배포 주소를 승인된 JavaScript 원본에 추가합니다.
  4. 공유할 Drive 폴더 주소를 입력합니다.
