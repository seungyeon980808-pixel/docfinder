# 한글 문서 일치 수 수정 검수

## 원인과 수정

한글 문서의 문단 텍스트만 추출하던 색인이 도식의 텍스트 상자를 누락했다. 원문 강조는 페이지 레이아웃의 텍스트를 사용하여 검색 목록과 수가 달랐다.

색인과 원문 강조가 같은 페이지 텍스트와 연결 규칙을 사용하도록 통일했다. 한글 색인 버전은 3이며, 배포 후 기존 HWP/HWPX를 백그라운드에서 다시 색인한다. 기존 쪽은 새 결과를 게시할 때까지 유지한다. 원본 파일과 접근 권한은 바꾸지 않는다. 재색인 버전이 문서함 및 공유 링크의 캐시 리비전에 반영된다.
