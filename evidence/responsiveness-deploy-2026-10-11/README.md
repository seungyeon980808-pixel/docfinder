## 사전 검증

운영 Dockerfile과 같은 Node 24 계열(v24.19.0)에서 단위/통합 테스트 197개 통과, 실패·건너뜀 0. 원본 저장/편집/실행 취소 기능과 권한 격리를 포함한다. 로컬 반복 측정은 ../responsiveness-2026-10-10/README.md에 기록되어 있으며 운영 성능 수치가 아니다.

Node 24의 Chromium 데스크톱, WebKit 데스크톱, WebKit 모바일 기능 검증을 통과했다. 첫 전체 시도는 기존 한글 편집기 초기화 대기 30초에서 시간 초과했다. Chromium 재실행은 같은 30초 조건으로 통과했다. WebKit에서 웹폰트 로딩 중임을 실패 화면으로 확인한 뒤 테스트의 편집 준비 대기를 90초로 늘렸고 실제 편집·저장·실행 취소·다시 실행과 모바일 표시 검증까지 통과했다. 제품의 폰트·편집 엔진을 바꾸거나 검사를 생략하지 않았다. 외부 폰트 준비의 지연은 이번 반응성 개선의 성과로 주장하지 않는다.

## 운영 설정 확인

Render UI에서 DocFinder 실행 인스턴스는 Free(0.1 CPU, 512MB), 5E 서비스는 별도의 유료 0.5 CPU, 512MB 인스턴스임을 확인했다. 워크스페이스는 Hobby이다. 기존 설정을 유지하고 자동 배포 Off 상태에서 승인된 커밋을 수동 배포한다. Docker build context는 프로그램 파일만 허용하며 개인 원본·로컬 색인·.env·테스트 증빙을 이미지에 넣지 않는다.

배포 결과와 실제 Safari 검수는 작업 완료 후 별도 결과 파일에 기록한다.
