# 실제 Safari 로컬 검수 — 2026-10-10

실제 macOS Safari에서 `http://localhost:4173/`를 새 탭으로 열어 연결된 로컬 폴더의 자료를 확인했다. 기존 5E 탭은 유지했다. 초기에는 Mac 잠금으로 조작이 막혔으나 이후 잠금 해제가 확인되어 아래 검수를 완료했다.

- 목록 15개와 `색인 15/15`, 자동 갱신 표시 확인.
- 검색 범위를 문서 내용으로 바꾸고 띄어쓰기 구절과 쉼표를 포함한 두 검색어 AND 검색 실행. 5개 결과와 `2/2개 포함` 표시 확인.
- PDF 선택 시 왼쪽 선택 파일 표시와 오른쪽 파일 제목이 일치. 실제 원문과 두 검색어의 서로 다른 강조색 표시 확인.
- 해당 PDF의 첫 검색 위치에서 다음 버튼 클릭: `1 / 486곳` → `2 / 486곳`. 현재 쪽 `3 / 38쪽`에서 다음 검색 위치를 강조. 파일 선택과 검색 입력은 동일하게 유지.
- 오른쪽 `원문 작업 중` 표시, 왼쪽 선택된 행의 배경과 `선택됨` 표시, 전체 페이지 검색 위치 막대 확인.
- 원문을 눈으로 확인한 Safari 화면은 대화에 표시했으며, 개인 문서 이름·본문이 들어간 화면을 저장소 증빙 파일에 복사하지 않았다.
- 검수 후 DocFinder 로컬 탭과 localhost:4173 서버를 유지했다. 운영 사이트 배포는 수행하지 않았다.

이 기록은 실제 Safari의 기능 검수다. 성능 비교 수치는 Chromium에서 동일 조건으로 별도 측정했고, 저장·실행 취소·원본 품질의 정밀 검수는 합성 문서로 Chromium/WebKit에서 수행했다. 실제 개인 문서는 수정하지 않았다.
